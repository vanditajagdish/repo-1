# Saloni & Kunwar — Wedding Website

A five-page wedding website styled after the save-the-date card: wine velvet, burnished gold foil, speckled olive leaves and blush lilies.

| Page | File |
| --- | --- |
| Home (save-the-date card, countdown, welcome) | `index.html` |
| Our Story (timeline) | `story.html` |
| Celebrations (Mehendi, Haldi, Sangeet, Wedding, Reception) | `celebrations.html` |
| Travel & Stay (venue map, arrivals, hotels, tips) | `travel.html` |
| RSVP (form + FAQ) | `rsvp.html` |

## Run locally

It's a plain static site with no build step:

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

To publish, upload the folder to any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages).

## Before going live

- **RSVP delivery** — in `rsvp.html`, set `data-email` on the form (currently `rsvp@example.com`) to your address, *or* set `data-endpoint` to a form service URL such as Formspree (`https://formspree.io/f/…`) to collect replies online. Also update the contact email in the FAQ.
- **Content** — the story chapters, event times, sub-venues, dress codes and hotel suggestions are placeholders written to fit the theme; edit them to match your plans.
- **Countdown** — the target time is the `data-countdown` attribute in `index.html`.

## Artwork

All florals are vector SVGs in `assets/img/`, so they stay sharp at any screen resolution. They are generated by `tools/generate_florals.py`; tweak colours or positions there and re-run:

```sh
python3 tools/generate_florals.py
```
